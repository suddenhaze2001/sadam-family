# Sadam Family Website Prototype

A responsive React + Vite family-memory website prototype with:

- Unique animated loading screen
- Personalized family passcodes
- Responsive family gallery
- Photo/video/favorites filters and search
- Memory detail cards
- Family upload prototype
- Guest upload-only page
- Children's star game

## Run on Windows

1. Extract the ZIP.
2. Open PowerShell inside the extracted `sadam-family-website` folder.
3. Run:

```powershell
npm install
npm run dev
```

4. Open the Local URL shown by Vite.
5. Stop the local server with `Ctrl+C`.

## Important security note

This is a frontend prototype. The demo keys are visible in the source code and are not suitable for protecting real family media. Before uploading private photos or publishing the site, connect secure server-side authentication and private cloud storage. Guest uploads also require time-limited upload tokens, file validation, storage rules and an approval queue.
